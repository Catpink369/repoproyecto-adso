# qa/Métricas/

Indicadores de calidad y avance de pruebas.

- `Informe_Checklist.docx` — total de RF, RF por prioridad (Alta/Media/Baja), % de ejecución por tipo de prueba (unitaria/integración/manual).
- `Matriz_Calidad_ISO.xlsx` — evaluación según características ISO/IEC 25010.
- `Dashboard_QA.xlsx` — % de avance por prioridad (Alta 100%, Media/Baja 75%), consistente con los criterios de salida del Plan Maestro, y bugs abiertos por severidad.
