# qa/Bugs/

Registro y reporte de defectos (bugs) encontrados durante la ejecución de pruebas.

- `Reporte_Bugs.xlsx` — plantilla con ID de bug (BUG-XXX), RF/CP afectado, severidad, estado, evidencia asociada.
- Los bugs también se registran como **GitHub Issues** (ver `.github/ISSUE_TEMPLATE/`), según la convención del equipo.

Convención de ID: `BUG-001`, `BUG-002`... correlativo único para todo el proyecto (no reinicia por módulo).
