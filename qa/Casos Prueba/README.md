# qa/Casos Prueba/

Casos de Prueba (CP) diseñados a partir de las Historias de Usuario y Requisitos Funcionales.

Archivos que van aquí:
- `Checklist.xlsx` — estado de completitud de cada RF (RN, entradas/salidas, CP asociados).
- `Casos_Prueba.xlsx` — detalle de cada CP (pasos, datos de entrada, resultado esperado).

Mismo esquema de versionado que el Plan Maestro (`Versiones/v1.0/`, `v1.1/`...).
