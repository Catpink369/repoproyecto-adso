# qa/Plan Maestro/

Plan Maestro de Pruebas (P-QA-09) del proyecto Gurama Online.

## Estructura sugerida
```
Plan Maestro/
├── Plan_Maestro_de_Pruebas.docx   (versión vigente, editable)
└── Versiones/
    ├── v1.0/Plan_Maestro_de_Pruebas_v1.0.docx
    ├── v1.1/Plan_Maestro_de_Pruebas_v1.1.docx
    └── ...
```
Regla del equipo: toda edición relevante genera una nueva versión (v1.1, v1.2...) que se archiva en `Versiones/`, y se agrega una fila en la tabla de Historial de Cambios del documento vigente. La numeración inicia en v1.0 (primera versión aprobada).
